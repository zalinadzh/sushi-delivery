# Sushi Black - Проект с душой!

Это мой самый любимый проект, который растет вместе со мной. Я не создала его за один вечер по готовому шаблону - я строю его по кирпичикам с самого начала моего пути в IT.

  ## Моя история в этом коде:
  Я возвращаюсь к этому сайту после каждой новой изученной темы.

  -Когда я учила CSS, я часами подбирала этот идеальный темный фон и настраивала отступы, чтобы все выглядело эстетично.
  -Когда мы начали Flexbox, я перестроила все расположение элементов, чтобы карточки роллов стояли ровно, как по линеечке.
  -Сейчас я внедряю JavaScript, чтобы этот сайт перестал быть просто картинкой. Теперь он будет уметь считать сумму заказа, проверять условия доставки и применять скидки.

Для меня "Sushi Black" - это доказательство того, что если вкладывать в работу сердце и упрямство, то из простых тегов рождается что-то красивое и осмысленное.
